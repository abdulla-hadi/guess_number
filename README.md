# Угадай число 

Консольная игра на Python. Компьютер загадывает число от 1 до 100, игрок угадывает, а программа подсказывает "больше" или "меньше".

## Как запустить 

python3 main.py

## Что внутри 

- цикл while для игры до победы 
- проверка ввода через try/except (игра не падает, если ввести слово)
- счетчик попыток
